# Indian Rider — Monsoon Rush 🛵

A compact 3D arcade delivery-driving game set on chaotic Indian city streets. Dodge traffic, autos, buses and cows, collect delivery drops, and beat the clock.

## Gameplay
- Third-person 3D scooter driving
- Five-lane arcade steering
- Traffic hazards: cars, auto-rickshaws, buses and cows
- Timed delivery pickups and rupee scoring
- Rainy street atmosphere
- Keyboard and mobile touch controls

## Controls
- **A / D** or **← / →** — steer
- **Space** — brake
- **Mobile** — on-screen left, right and brake controls

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
